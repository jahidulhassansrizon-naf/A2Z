# A to Z Management System

A full-stack web application built for managing users and administrators with secure authentication, real-time chat, and file sharing features.

## Features
- Separate login and registration system for Admin and Users.
- Gmail OTP verification for secure user registration.
- Admin panel to view total registered and active users, and send direct emails.
- Real-time chat system between users and the admin for support.
- File sharing and downloading system where the admin can send files and track user download history.

## Tech Stack
- Frontend: HTML, CSS, JavaScript, React
- Backend: Node.js, Express.js
- Database: MongoDB
